# TrustLens OLX Capture Extension — Compatibility Specification

This document details how the JSON output produced by the `capture-olx` Chrome extension maps to the existing TrustLens Python marketplace schema (`src/trustlens/olx/models.py`), explains field availability from the OLX DOM, and provides a sample ingestion adapter for downstream Python processing.

---

## 1. Schema Mapping Matrix

| Extension JSON Field | Target TrustLens Python Model & Field | Mapping Status | Notes |
| :--- | :--- | :--- | :--- |
| `listing_id` | `OLXListing.source_listing_id` | **Direct** | Numeric OLX listing ID extracted from `iid-` or card anchor. |
| `source_url` | `OLXListing.listing_url` | **Direct** | Fully-qualified URL to the OLX item. |
| `raw.title` / `normalized.title` | `OLXListing.title` | **Direct** | Title text from DOM `[data-aut-id="itemTitle"]`. |
| `normalized.price.amount` | `OLXListing.price` | **Direct** | Parsed numeric float (e.g., `58000.0`). |
| `normalized.price.currency` | `OLXListing.currency` | **Direct** | Defaults to `"INR"`. |
| `raw.location` / `normalized.location` | `OLXListing.location` | **Direct** | Displayed city/locality string. |
| `description.text` | `OLXListing.description` | **Direct** | Text from `[data-aut-id="itemDescriptionContent"]`. |
| `attributes` (Dictionary) | `OLXListing.product.attributes` | **Direct** | Generic key-value dictionary extracted from `[data-aut-id="itemParams"]`. |
| `attributes.Brand` | `OLXListing.product.brand` | **Direct / Extracted** | Mapped from key `"Brand"` or `"Make"`. |
| `attributes.Model` | `OLXListing.product.model` | **Direct / Extracted** | Mapped from key `"Model"`. |
| `attributes.Storage` | `OLXListing.product.storage` | **Direct / Extracted** | Mapped from key `"Storage"`. |
| `attributes.Condition` | `OLXListing.product.condition` | **Direct / Extracted** | Mapped from key `"Condition"`. |
| `media[].src` | `OLXListing.media[].source_url` | **Direct** | High-resolution image URLs (deduplicated against Slick clones). |
| `capture_context.search_query` | `DiscoveryContext.query` | **Direct** | Query string from `/q-...` slug or search param. |
| `capture_context.category_id` | `DiscoveryContext.category` | **Direct** | Category ID from `_c...` slug or data attribute. |
| `capture_context.source_url` | `DiscoveryContext.search_url` | **Direct** | Originating search URL. |
| `captured_at` | `OLXCollectionMetadata.collected_at` | **Direct** | ISO-8601 timestamp of capture. |

## 2. Extension-Specific Fields (Preserved for Research)

These fields are retained in the extension's export payload to prevent loss of observed data:

* **`raw`**: Exact textual representations (`raw.price`, `raw.date`, `raw.location`, `raw.title`, `raw.description`) as rendered on the page before normalization.
* **`description.paragraphs`**: Array of individual paragraph strings preserving the line-break structure of the listing.
* **`contact_actions`**: Observable UI interaction controls (`chat_available`, `call_available`, `favourite_available`).
* **`badges`**: Visual platform markers (`featured`, `verified`, `elite`).
* **`media[].gallery_index` & `media[].file_id`**: Ordered position and Apollo file ID for asset tracking.

---

## 3. Fields Not Observable in OLX DOM (Faithfully Null)

The public OLX DOM does not expose certain backend profile and identity attributes without active authentication or chat interactions. To prevent hallucinated data, the extension leaves these as `null`:

* **`seller.display_name`**: Not exposed in standard card or listing DOM.
* **`seller.profile_url`**: No public profile link rendered on modern OLX listings.
* **`seller.account_age`**: Not available in static listing HTML.
* **`seller.listing_count`**: Not available in listing DOM.
* **`seller.business_claim`**: Left `null` unless explicit verified business markers are observed.

TrustLens analytical fields (`claims`, `evidence`, `signals`, `verification_checks`) are **not generated by the extension**; they are computed strictly within the Python pipeline downstream.

## 4. Downstream Ingestion Adapter (Example)

When ingesting exported JSON files into TrustLens, an adapter function can load the capture envelope and convert each listing into standard `OLXListing` model instances:

```python
import json
from datetime import datetime, timezone
from pathlib import Path
from typing import List

from trustlens.olx.models import (
    CollectionMethod,
    CollectionType,
    DiscoveryContext,
    OLXCollectionMetadata,
    OLXListing,
    OLXMedia,
    OLXProduct,
    OLXSeller,
)


def load_extension_capture(json_path: str | Path) -> List[OLXListing]:
    """Convert an exported capture JSON file into TrustLens OLXListing objects."""
    with open(json_path, "r", encoding="utf-8") as f:
        data = json.load(f)

    listings: List[OLXListing] = []
    idx = 1

    for capture in data.get("captures", []):
        ctx_data = capture.get("capture_context", {})
        disc_context = DiscoveryContext(
            investigation_id="INV-002",
            query=ctx_data.get("search_query"),
            category=ctx_data.get("category_id"),
            search_url=capture.get("source_url"),
            discovered_at=datetime.fromisoformat(capture["captured_at"].replace("Z", "+00:00")),
        )

        for item in capture.get("listings", []):
            attrs = item.get("attributes", {})
            prod = OLXProduct(
                brand=attrs.get("Brand") or attrs.get("Make"),
                model=attrs.get("Model"),
                storage=attrs.get("Storage"),
                condition=attrs.get("Condition"),
                attributes=attrs,
            )

            media_objs = [
                OLXMedia(
                    media_id=f"MED-{m.get('file_id') or i:04d}",
                    listing_id=f"OLX-{idx:06d}",
                    source_url=m["src"],
                    download_status="pending",
                )
                for i, m in enumerate(item.get("media", []))
            ]

            listing = OLXListing(
                listing_id=f"OLX-{idx:06d}",
                source="olx",
                source_listing_id=item.get("listing_id"),
                listing_url=item.get("source_url") or capture.get("source_url"),
                investigation_id="INV-002",
                collection_type=CollectionType.TARGETED,
                title=item.get("normalized", {}).get("title") or item.get("raw", {}).get("title") or "OLX Item",
                description=item.get("description", {}).get("text") or "",
                price=item.get("normalized", {}).get("price", {}).get("amount"),
                currency=item.get("normalized", {}).get("price", {}).get("currency") or "INR",
                location=item.get("normalized", {}).get("location"),
                product=prod,
                seller=OLXSeller(),
                media=media_objs,
                discovery_context=disc_context,
                collection_metadata=OLXCollectionMetadata(
                    collection_method=CollectionMethod.BROWSER_EXTENSION,
                    discovered_via="researcher_capture",
                ),
            )
            listings.append(listing)
            idx += 1

    return listings
```
